# Free Web Tools

ブラウザ上でインストール不要・完全無料で使える便利なWebツール集です。
すべてのツールはクライアントサイド（ブラウザ内）で完結するため、入力データが外部サーバーに送信されることはなく安全に利用できます。

🔗 **公式サイト / ツール一覧（Web版）:**
https://kurenaivoid.github.io/free-web-tools/

## ✨ 特徴 (Features)
* **完全無料・登録不要:** アカウント作成やログインなしで即座に利用可能。
* **プライバシー保護（ローカル処理）:** すべての処理はユーザーのブラウザ（JavaScript）上で実行され、サーバーへのデータアップロードは一切行いません。
* **軽量・高速動作:** 余計なライブラリを排除した単一HTML/JS構成により、PC・スマホ問わず軽快に動作します。
